# Pollution Reclamation

Pollution Reclamation is a Factorio 2.1 mod that adds a standalone air purification and pollution filtering system.

Build the air purifier to consume electricity and pollution filters to actively erase pollution around your factory. Used filters can be restored with water, and an advanced filter tier unlocks higher throughput and, on Space Age saves, filtering of Gleba's airborne spores.

This mod continues an independent line of KrastorioAirPurifier by Tarckmhog, itself a port of the air purifier from Krastorio 2 by raiguard, Krastor, and Linver. KrastorioAirPurifier has no public source repository, so this is a from-scratch continuation rather than a fork.
